CASE STUDY / 01

KrishiMind AI

An AI-powered agriculture platform designed to help analyze crop images and identify possible plant diseases.

Open Live Demo ↗View GitHub ↗← Portfolio

01 / Overview

From crop image to AI prediction.

KrishiMind AI combines a React frontend with a Flask and TensorFlow backend to create an agriculture-focused disease detection workflow.

The crop scanner accepts a plant image, sends it to the prediction API and returns the predicted class with a confidence score. Firebase authentication is used for the application experience.
